# یادآور کارها (Android)

اپ فارسی برای ثبت کارهای یک‌بار، روزانه و ماهانه (تقویم شمسی) و اعلان سررسید.

## ساخت و اجرا
1. Android Studio (نسخهٔ Koala یا جدیدتر) را باز کن → **Open** → پوشهٔ `TaskReminder`.
2. صبر کن Gradle Sync تمام شود (اولین بار اینترنت لازم است؛ فایل `gradle-wrapper.jar` را خود Android Studio می‌سازد).
3. گوشی را با USB وصل کن (Developer options / USB debugging روشن) و **Run ▶** بزن.
4. برای APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## امکانات
- کار یک‌بار: تاریخ شمسی + ساعت
- کار روزانه: هر روز در ساعت مشخص
- کار ماهانه: روز مشخصی از ماه شمسی (اگر ماه آن روز را نداشته باشد، آخرین روز ماه)
- اعلان دقیق در سررسید، با دکمهٔ «انجام شد» روی خود اعلان
- زدن تیک «انجام شد»: کار یک‌بار بسته می‌شود؛ کار تکراری به نوبت بعدی می‌رود
- بعد از ریبوت یا تغییر منطقهٔ زمانی، آلارم‌ها دوباره تنظیم می‌شوند

## نکته برای اعلان روی بعضی گوشی‌ها
در گوشی‌های شیائومی، سامسونگ، هوآوی و ... اگر اعلان‌ها دیر می‌آیند، در تنظیمات باتری، اپ را روی **Unrestricted / بدون محدودیت** بگذار.
